# 🪚 כרטיס דיגיטלי - התקנות ישראל ישראלי

**כרטיס דיגיטלי מעוצב** שנבנה בעזרת React ו- Material UI.
הכרטיס מאפשר ללקוחות ליצור קשר ישיר דרך WhatsApp, דוא״ל או רשתות חברתיות — וגם לראות שירותים, יתרונות, ולבקש הצעת מחיר בלחיצה אחת.

---

## 🚀 טכנולוגיות

* ⚛️ **React + Vite** – לביצועים מהירים וממשק מודרני
* 🎨 **Material UI (MUI)** – לעיצוב נגיש, רספונסיבי ואלגנטי
* 💅 **Emotion + RTL** – תמיכה מלאה בכיווניות ימין-לשמאל (עברית)
* ✨ **אנימציות כפתור זהב** – אפקט מעבר חלק שמושך את תשומת הלב

---

## 🧱 מבנה הפרויקט

```
src/
├── App.js                 # עיצוב כללי וערכות נושא
├── DigitalBusinessCard.js # מרכיב הכרטיס הדיגיטלי הראשי
├── assets/
│   └── avatar.png         # תמונת האווטר (איש עם כיפה)
└── index.css              # עיצוב כללי נוסף
```
